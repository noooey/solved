# 3752. 가능한 시험 점수

## Code (Python)
```python3
from itertools import combinations
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    # ///////////////////////////////////////////////////////////////////////////////////
    N = int(input())
    scores = list(map(int, input().split()))
    possible_scores = {0}

    for s in scores:
        new_scores = {n + s for n in possible_scores}
        possible_scores |= new_scores

    print(f"#{test_case} {len(possible_scores)}")
    # ///////////////////////////////////////////////////////////////////////////////////
```

## Complexity
- Time: O(nm)
