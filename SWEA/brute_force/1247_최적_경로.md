# 1247. [S/W 문제해결 응용] 3일차 - 최적 경로

## Code (Python)
```python3
from itertools import permutations

T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    N = int(input())
    locs = list(map(int, input().split()))
    customers = []
    for i in range(N+2):
        customers.append((locs[2 * i], locs[2 * i + 1]))
    start, end = customers[0], customers[1]
    min_dist = float('inf')
    # 집, 회사 제외 나머지에 대한 순열
    for per in permutations(customers[2:], N):
        dist = 0
        x, y = start[0], start[1]
        for px, py in per:
            dist += abs(px-x) + abs(py-y)
            x, y = px, py
        dist += abs(end[0]-x) + abs(end[1]-y)
        min_dist = min(dist, min_dist)

    print(f"#{test_case} {min_dist}")
```

## Complexity
- Time: O(n!)

## Notes
- Brute force
